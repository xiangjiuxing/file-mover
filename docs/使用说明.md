# 文件搬运工具 v2.3 · 使用说明

> **作者：微尘** · 2026-11-08 · 纯本地运行，不联网、不上传任何文件

## 🚀 直接打开

双击 **`文件搬运工具.exe`**（单文件，约 23 MB）即可，**不需要安装 Python、不需要装任何依赖**：拖拽组件 tkdnd、高清图标资源，以及用于抗锯齿圆角绘制的 Pillow 都已打进包里。

如果以后改了源码想直接跑 Python 版，双击 `启动.bat`（无黑框）或 `调试启动.bat`（带控制台看报错）。
右键 `文件搬运工具.exe` → 发送到 → 桌面快捷方式，最方便。

> EXE 会把 `常用目标.json`、`搬运日志.txt`、`错误日志.txt` 写在 **EXE 所在目录**，方便备份和查看。

## 🎨 v2.3 视觉改版（本次更新，功能与交互不变）

### ① 重点：按钮圆角锯齿被彻底修掉

**原因**：旧版按钮和卡片用 Canvas 的 `create_oval` 拼圆角，而 Tk 的 Canvas **没有抗锯齿能力**，圆角弧线只能由整数像素的椭圆硬拼出来，放大后就是明显的阶梯状锯齿。按钮越小、越亮，锯齿越扎眼。

**修复**：新增 `aa_rounded()` —— 用 **4 倍超采样**绘制圆角位图，再以 **LANCZOS** 缩回目标尺寸，生成一张「透明底 + 平滑圆角」的 PNG 交给 Tk 的 `PhotoImage` 显示：

- **任意尺寸**：52×28 的小预设按钮到 196×34 的主按钮，都是同一套算法，实测每张图都有 19 级以上的 alpha 过渡像素（即平滑边缘，不是硬切）；
- **任意状态**：normal / hover / disabled 三种颜色各自的图都走同一条抗锯齿路径，边缘一致干净；
- **卡片同样处理**：白卡与它下方的暖阴影都是抗锯齿圆角图，不再有椭圆拼圆的锯齿；
- **降级保护**：万一运行环境缺 Pillow，会自动回退到旧画法，界面不会崩、功能不受影响（只是圆角带锯齿）。

按钮圆角统一为 **9 px**、卡片统一 **14 px**，不再随高度变成胶囊状，整体更利落一致。

### ② 配色：冷色 → 多巴胺暖色系

| 用途 | 新配色 |
| --- | --- |
| 窗口底 / 卡片 | 奶油暖白 `#FFF8EF` / 纯白 |
| 正文 | 深棕墨 `#3E2C26`（比纯黑柔和） |
| 主 CTA（开始搬运、添加文件、送去搬运） | **中黄 `#FFC53D`** + 深棕字 |
| 主要操作（添加目标、切换文件夹） | **珊瑚橙 `#FF7043`** |
| 次主要操作（星标管理、批量多个） | **玫红 `#F0478A`** |
| 点缀（日志区色点、10★、重命名） | 亮紫 `#9B6BFF` |
| 标题栏渐变 | 珊瑚橙 → **中黄** → 玫红 |

冷色只剩极少量青绿/蓝作点缀，占比大幅降低。大面积仍是奶油白与纯白，所以**明快热烈但不刺眼**。图标 `icon.ico` / `icon_ui.png` 也同步换成同款暖色渐变，保持品牌一致。

### ③ 层次、间距、对比度、一致性

- **亮底自动深墨字**：中黄等亮色按钮自动改用深棕文字（按相对亮度判断），不会再用白字糊在黄底上；珊瑚橙/玫红仍用白字。
- **标题栏文字加 1px 深棕投影**，保证渐变中段最亮的中黄上白字依然清晰。
- **卡片**新增柔和暖阴影、标题左侧彩色方点（直角，天然无锯齿）、标题区细分隔线，层次更清楚。
- **按钮水平间距统一**为 4 px；所有按钮圆角一致。
- **对比度**：输入框/列表/表头/滚动条/进度条/复选框选中态全部换成暖色；底部版权行文字加深。
- **几何尺寸刻意保持不变**：本机是 150% 缩放，窗口 `980×860` 刚好容纳四张卡片和版权行，任何高度增加都会把底部挤出窗口。因此这次只优化水平间距与视觉层次，**没有改动任何垂直高度**——两张最终截图均验证底部完整。

> `常见目标`、拖拽、多目标、扩展名过滤、星标管理、复制/移动安全策略等**功能与交互一行未改**。本次用「v2.2 备份 vs v2.3 同输入对比」的方式逐项验证过，见下方技术事实。

## 🆕 v2.2 更新内容（保留）

### ① 修复：在文件夹对话框里「新建文件夹」时界面分辨率突变

**原因（已查证）**：旧版「+ 多个文件夹」「+ 添加目标」用的是 `tkinter.filedialog.askdirectory`，在 Windows 上它调用的是系统 shell 目录对话框（SHBrowseForFolder）。这个对话框自带「新建文件夹」，弹出以及在里面新建目录时会触发进程 DPI 上下文切换，使原本 DPI-unaware 的 Tk 窗口被重新缩放。

**修复方式**：把**文件夹和文件的选择全部换成纯 Tk 自绘浏览器**（`BrowseFolderDialog`），完全不调用任何 Windows 系统对话框。新浏览器自带「+ 新建文件夹」「↑ 上级」/ 盘符下拉、「刷新」/ 双击进入、Ctrl / Shift 多选文件。

所有对话框尺寸锁定（浏览器 `660×500`、星标管理 `940×820`），`resizable=False` 且设了 `minsize`，全程不会跳变。

> **一条踩过的坑，如实记录**：本机是 **150% 缩放**（物理 2560×1600 / 逻辑 1707×1067；DPI-unaware 进程查 `GetDeviceCaps` 只会得到虚拟化的 96 DPI）。曾试过声明 `SetProcessDpiAwareness`，结果 `tk scaling` 从 1.332 跳到 1.998、字体放大 1.5 倍而窗口物理尺寸不变，四张卡片被挤出窗口，**已撤回**。现在只靠自绘浏览器从根源解决，不启用任何 DPI 声明。

### ② 新增：★ 星标管理器

**入口**：主界面「① 选择文件」→ 玫红色「**★ 星标管理**」→ 选一个文件夹 → 弹出显示框，列出该文件夹里的**所有顶层文件与子文件夹**（类型 / 星标 / 名称 / 大小）。

| 你要做的事 | 怎么操作 |
| --- | --- |
| **打 1~10 颗星** | 单击选中一项，或 Ctrl / Shift 多选，点 `1★` ~ `10★` 共 10 个按钮（颜色按 橙 → 黄 → 玫红 → 紫 暖色梯度） |
| **看前缀提示** | 打星后名称前自动加括号提示，例如 `(★★★) 报告.pdf`；再打星只替换前缀、不叠加，原名和扩展名不变 |
| **按星标筛选** | 下拉选「全部 / 未标星 / 1★ … 10★」；勾「≥ 该星级及以上」变成区间筛选，列表实时刷新 |
| **重命名** | 选中一项点「重命名选中」，或直接**双击该行**，输入完整新名称 |
| **清除星标** | 对选中项点 `清除`（0 星）；或点「清除全部星标」一键恢复原名（二次确认，只改前缀、不删文件） |
| **回到搬运** | 点「**把筛选结果送去搬运 →**」，当前筛出的项目回到主界面文件列表，继续原来的复制 / 移动流程 |

**真实截图见 `星标管理预览.png`**，主界面见 `界面预览.png`。

## 🛡 星标功能的安全设计

- **星标就是文件名前缀**，不用数据库、不写隐藏配置，资源管理器里也能直接看见；随时可一键清除还原。
- **绝不覆盖**：改名撞名时自动加 `_1` 序号；拒绝 `\ / : * ? " < > |`、首尾空格、句点结尾等非法名称。
- **绝不误删源文件夹**：筛选结果通常只是源文件夹的一部分。程序会强制把该文件夹标记为「不可整体清理」，移动模式只逐文件把**被筛中的**文件送回收站，源文件夹和其余文件原样保留（已专项自测验证）。
- **层级仍然保留**：筛出的文件落到 `目标 / 父文件夹名 / 文件`；筛出的子文件夹作为整体递归搬运。
- 重命名若因文件被占用 / 只读失败，会逐条提示，其余项目不受影响。

## ⚠️ 已知限制

- 星标管理器只显示所选文件夹的**顶层**项目；子文件夹作为整体，送出时递归搬运。
- 星标写在文件名里，只识别 `(★…★)` 这种 1~10 星前缀；自己手动写 11 星以上不会被识别。
- 拖拽需要 Windows 资源管理器正常拖入；若杀毒软件拦截 tkdnd，程序会自动降级为「仅按钮添加」并提示，不会崩溃。
- 本机为 150% 缩放，程序保持 DPI-unaware（由系统位图放大），字体略软但布局稳定；**不要**再启用 DPI 感知声明，否则界面会缩水（见上文踩坑记录）。
- 过滤规则只按**扩展名**匹配，不按文件内容。
- v2.3 起 EXE 因打入 Pillow 增至约 23 MB；若在意体积，可把 `--collect-all PIL` 换成按需收集，但需重新打包验证。
