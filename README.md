# file-mover · 文件搬运工具

> 一个**纯本地、Windows 桌面端**的批量文件搬运工具：多选 / 拖拽 / 多目标文件夹 / 扩展名过滤 / 星标管理 / 复制校验。
>
> 当前版本 **v2.3** · 作者 **微尘** · 许可证 [MIT](LICENSE)

## 项目定位

这是一个**面向个人日常整理的轻量桌面小工具**，解决一个很具体的动作：

> 从本地磁盘挑出若干文件（或若干整个文件夹），一次性复制或移动到一个或多个目标文件夹，并在过程中保证文件不被打散、不被误删。

它不是同步软件、不是网盘客户端、也不是命令行批处理器。程序只在本机运行，**不发起任何网络请求、不上传任何文件、不收集任何数据**。全部界面由 Python 标准库 `tkinter` 绘制，功能范围刻意保持很窄，以避免把简单操作变复杂。

## 适用场景

- 把散落在多个位置的文件，批量归集到一个或多个目标文件夹；
- 同一批资料需要同时备份到多个目录（例如移动硬盘 + 本地备份盘）；
- 只搬运某几类文件（按扩展名包含 / 排除，含图片、文档、视频快捷预设）；
- 拖入整个文件夹时，需要在目标位置**连同目录层级、子目录与空文件夹一起重建**；
- 需要对文件夹内的条目按重要性标 1–10 星，再只把筛选出来的部分送去搬运；
- 关心复制结果是否正确（按大小或 SHA-256 校验）、担心误删源文件。

### 不适用场景

- 大规模增量同步、双向镜像、定时自动同步（请改用 FreeFileSync / Robocopy 等专业工具）；
- 跨设备、云端、多人协作或移动 / macOS / Linux 平台；
- 需要保留 NTFS 权限、备用数据流、符号链接语义等特殊文件系统属性；
- 需要无人值守、命令行脚本化或服务化运行。

## 使用前提

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（依赖 Tk、tkdnd 与 Windows 回收站接口，其他平台未适配） |
| 运行方式 A | 已打包的独立 EXE，双击即可，**无需安装 Python** |
| 运行方式 B | Python 3.10+（开发机实测 3.12.8），自带 `tkinter` |
| 可选依赖 | `tkinterdnd2`（拖拽）、`Pillow`（抗锯齿圆角）；两者缺失时程序会**自动降级**，不会崩溃 |
| 打包依赖 | 仅自行打包 EXE 时需要 `PyInstaller` |
| 权限 | 对源路径有读权限、对目标路径有写权限；移动模式需要回收站可用 |
| 字体 | 界面使用 `Microsoft YaHei UI`（Windows 自带） |

> ⚠️ **星标功能会真实修改磁盘上的文件名**（在名称前加 `(★★★) ` 前缀），在资源管理器里同样可见，且可一键清除还原。请勿对正在被其他程序占用的文件使用。

## 快速开始

### 方式 A：源码运行

```bash
python -m pip install tkinterdnd2 Pillow
```

然后双击 `启动.bat`（无控制台）或 `调试启动.bat`（保留控制台便于看报错），也可以直接：

```bash
python app.py
```

### 方式 B：自行打包独立 EXE

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name FileMover --icon icon.ico --add-data "icon.ico;." --add-data "icon_ui.png;." --collect-all tkinterdnd2 --collect-all PIL app.py
```

> 本仓库**只保存源码，不纳入二进制 EXE**（`.gitignore` 已排除）。免安装包请从 [v2.3.0 Release](https://github.com/xiangjiuxing/file-mover/releases/tag/v2.3.0) 下载 `FileMover-v2.3.0-Windows-x64.exe`（约 23 MB，双击即用，无需 Python，下载后可随意改名）；也可按上面的命令自行生成。
>
> `app.py` 通过 `resource_path()` 从**自身所在目录**读取 `icon.ico` / `icon_ui.png`，因此主程序与图标文件必须保持同级，请勿擅自拆分目录，否则源码运行与打包都会找不到资源。

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 添加来源 | 多选文件、批量添加多个文件夹、直接把文件 / 文件夹拖入窗口；可选是否递归含子目录 |
| 目标 | 可添加多个目标文件夹，每个文件复制到每一个目标；支持存为「常用目标」 |
| 目录层级 | 文件夹按 `目标\文件夹名\相对路径` 重建，含子目录与空文件夹，不会打散 |
| 过滤 | 按扩展名「仅包含 / 排除」，支持 `jpg, .png pdf` 混合写法与快捷预设，列表实时刷新 |
| 动作 | 复制（默认，源保留）/ 移动（全部成功后源送**回收站**，可还原） |
| 同名处理 | 自动改名 `报告_1.txt` / 覆盖 / 跳过 |
| 校验 | 默认按大小，可开 SHA-256 逐字节校验；失败只删除本次生成的不完整副本 |
| 星标管理 | 1–10 星写入名称前缀、按星筛选（含「≥ 该星级及以上」）、重命名、一键清除、筛选结果送回搬运 |
| 留痕 | 结果实时显示，并写入程序目录下的 `搬运日志.txt` |
| 界面 | 多巴胺暖色系、4× 超采样抗锯齿圆角、纯 Tk 自绘目录浏览器（不调用系统目录对话框） |

## 安全与隐私

- 源码中**没有任何网络请求调用**，程序不联网、不上传、不写注册表。
- 运行时会在**程序所在目录**生成 `常用目标.json`、`搬运日志.txt`、`错误日志.txt`。这些文件可能包含你自己的本地路径与文件名，**已加入 `.gitignore`，请勿提交或公开分享**。
- 移动模式只有在某文件于**所有目标**都成功且校验通过后，才把源送入回收站；任一目标失败或被跳过，源文件一律保留。筛选出的部分条目会强制禁用「整体清理」，避免误删同目录下未选中的文件。
- 星标与重命名作用于真实文件名，撞名自动加序号、绝不覆盖，非法字符会被拒绝。
